DCTHash vs BlurHash, same string length

Drop an image. Both placeholders are encoded and decoded in your browser; nothing is uploaded. The BlurHash component grid sets the string length, and DCTHash is encoded at exactly that many characters.

PSNR is measured against the image shown on the left, at the displayed resolution; higher is better. BlurHash is encoded as in the reference C implementation with the chosen grid (swapped for portrait images) and decoded with the blurhash npm package; that package's own encoder clips strong negative components, which would understate BlurHash. DCTHash also stores an approximate aspect ratio and exposes the average colour without decoding.
